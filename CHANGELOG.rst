============================================
Ap\_Labs.Freebsd\_Provisioning Release Notes
============================================

v1.0.0
======

Release Summary
---------------

Initial public release of the ap_labs.freebsd_provisioning collection, providing modular roles for FreeBSD node bootstrapping, system tuning, storage (ZFS/NFS/Samba), networking, virtualization (bhyve/Bastille), and monitoring.

New Modules
-----------

- ap_labs.freebsd_provisioning.localbase_facts - Gather FreeBSD user.localbase sysctl as a fact.
